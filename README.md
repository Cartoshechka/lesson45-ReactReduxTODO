# 📝 TODO Redux App

Современное приложение для управления задачами, созданное с использованием React, TypeScript и Redux Toolkit.

## ✨ Особенности

- ✅ Добавление, удаление и отметка задач как выполненных
- 🔍 Фильтрация задач (все, активные, выполненные)
- 📊 Подсчет активных задач
- 💾 Автоматическое сохранение в `localStorage` с помощью **Redux Persist**
- 🎨 Современный и адаптивный UI
- 🔧 Поддержка **Redux DevTools** для отладки

## 🛠️ Технологии

- **React** — библиотека для создания пользовательских интерфейсов
- **TypeScript** — строгая типизация для надежного кода
- **Redux Toolkit** — современный и эффективный способ работы с Redux
- **Redux Persist** — библиотека для сохранения состояния приложения
- **Vite** — быстрый инструмент для сборки и разработки

## 📦 Установка и запуск

### 1. Установка зависимостей

Используйте вашу любимую систему управления пакетами:

```bash
yarn install
# или
npm install
```

### 2. Запуск в режиме разработки

```bash
yarn dev
# или
npm run dev
```

### 3. Сборка проекта

```bash
yarn build
# или
npm run build
```
